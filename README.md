# «Пища с любовью» • Рупавати (Food with Love)

> **Скоростной лендинг-экосистема для кулинарной книги и проектов Рупавати (Юлии)**  
> Разработано на базе чистого, ультра-быстрого стека (HTML5 + CSS3 + Vanilla JS) без тяжелых зависимостей и сборщиков.

---

## 🌟 Особенности реализации

1. **Мгновенная скорость загрузки:**
   - Нет тяжелых фреймворков и лишних скриптов.
   - Оптимизированные изображения из оригинальной книги (Canva PDF).
   - Google Fonts (`Cormorant Garamond` для благородного книжного стиля + `Plus Jakarta Sans` для удобства чтения).
   
2. **Интерактивные возможности:**
   - **Интерактивный тест на 3 Доши (Ayurveda Quiz):** определяет ведущую конституцию (Вата, Питта, Капха) и сразу рекомендует блюда из книги со страницами.
   - **Модальный просмотр книги (Look Inside):** интерактивная галерея реальных разворотов высокого разрешения (каша, дал, кутабы, манго-карри, чизкейк, наполеон).
   - **Фильтрация рецептов:** завтраки, супы, основные блюда, десерты.
   - **Двуязычность (RU / EN):** мгновенное переключение языка в один клик.
   - **Модули будущей экосистемы (заглушки с листом ожидания):** закрытый клуб по подписке, видео-курсы по специям, выездные ретриты, индивидуальные консультации.
   - **Синергия с Telegram-каналом:** стилизованный блок с живым чатом и отзывами, привлекающий аудиторию в канал Рупавати.

## 🚀 Как запустить для демонстрации Рупавати

### Вариант 1: В один клик (Windows)
Просто дважды кликните по файлу **`start_preview.bat`** в папке `G:\11 Rupavati site`.
Он запустит локальный HTTP-сервер на порту 3000 и сам откроет браузер по адресу:  
👉 **`http://localhost:3000`**

### Вариант 2: Прямое открытие файла
Дважды кликните по **`index.html`** — он откроется в любом браузере (Chrome, Edge, Яндекс, Safari).

## 🌐 Варианты бесплатной публикации в интернете (1–2 минуты)

Сайт полностью автономен и не требует серверов или баз данных на старте. Его можно опубликовать бесплатно:

1. **GitHub Pages:**
   - Создать бесплатный репозиторий `rupavati-preview-7x9k2m` на GitHub.
   - Загрузить файлы проекта.
   - В настройках репозитория включить *Settings -> Pages -> Deploy from main branch*.
   - Сайт будет доступен по адресу `username.github.io/rupavati-preview-7x9k2m` или на персональном домене `rupavati.ru`!

2. **Cloudflare Pages / Vercel / Netlify:**
   - Перетащить папку с сайтом мышкой в окно сервиса (Drag & Drop).
   - Получить моментальный бесплатный HTTPS-домен и неограниченный быстрый CDN по всему миру.
